⚠️ Du hast die App als lokale Datei geöffnet

Browser erlauben das Mikrofon auf file://-URLs nicht dauerhaft. Darum fragt es jedes Mal neu.
Schnellste Lösung: öffne cmd / PowerShell im Ordner mit der Datei und starte einen Mini-Server:
python -m http.server 8000   (oder mit Node: npx serve .)
Dann im Browser öffnen: http://localhost:8000
Noch besser: GitHub Pages aktivieren – siehe Chat.
