# Entwurf: Google-Unternehmensprofile für beide Firmen (Prüfung 4, 9)

Zwei getrennte Google-Business-Profile sind erlaubt, wenn sie **unterschiedliche Hauptkategorien** haben. Das war wahrscheinlich das Problem beim letzten Mal — beide wurden als dieselbe Kategorie angemeldet und Google hat Duplikate vermutet.

## Anmeldung

[business.google.com](https://business.google.com) → "Profil hinzufügen" → beide einzeln anlegen.

## Wichtig: gleiche Adresse, zwei Profile — so klappt es

Wenn beide Firmen **an derselben Adresse** sind:

1. **Zwingend zwei unterschiedliche Hauptkategorien** (siehe oben: Musikinstrumentengeschäft vs. Esoterikladen).
2. Idealerweise zwei verschiedene Telefonnummern. Wenn das nicht geht: wenigstens unterschiedliche Durchwahlen oder zwei eigene Mobilnummern.
3. Beide Firmen müssen rechtlich existieren — entweder als getrennte Einzelfirmen, GmbHs oder klar getrennte Marken einer Firma.
4. Beim Firmennamen **keine Kategoriewörter** doppeln ("Spirit Wellness Klangschalen" wäre tödlich — Google hält das für Duplikat).

## Verifizierung

Google schickt eine Postkarte mit Code (5–14 Tage). Code eingeben → Profil live.

Falls Verifizierung abgelehnt wird, Grund fast immer:
- Adresse stimmt nicht mit Handelsregister überein
- Profil wirkt wie Duplikat (siehe Punkt 1 oben)

Bei Ablehnung: nicht nochmals einreichen mit leichten Änderungen — sondern Google-Support öffnen und erklären, dass es zwei getrennte Marken sind. Belege bereithalten: zwei verschiedene Websites, zwei verschiedene Kategorien, Handelsregisterauszug.

## Nach Live-Schaltung

- Wöchentlich 1 Foto hochladen (Produkt oder Lager).
- Jede Woche 1 Google-Post (Angebot, Neuheit, Saisonales).
- Jede Bewertung innerhalb 48 h beantworten (siehe `bewertungsbitte.md`).
